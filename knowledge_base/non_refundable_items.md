# What Is Not Refundable

The following are excluded from our standard refund policy and cannot be refunded
under any circumstances, including within the normal 30-day window:

- One-time setup or onboarding fees
- Custom integration or professional services work already delivered
- Add-on credit packs that have been partially or fully consumed
- Any charge older than 180 days, regardless of the reason

Usage-based overage charges (for example, exceeding an API call quota) are also
non-refundable, since they reflect resources that were actually consumed.

If a customer requests a refund for one of these items, explain the exclusion
clearly and, if appropriate, offer an account credit as a goodwill gesture instead —
but note that goodwill credits still require supervisor sign-off if the value
exceeds $50.
